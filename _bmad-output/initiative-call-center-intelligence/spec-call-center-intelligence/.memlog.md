- (direction) Input is rich; extract directly, no elicitation. Slug inherited from brief-call-center-intelligence.
- (decision) Why = pain + mandate: 5,000 calls/day, <5% manually reviewed at ~15 min each, 40-60% inter-rater agreement, problems surface next day, no audit trail or disclosure proof in regulated industries.
- (capability) CAP-1 Intake: reject audio by content (magic bytes, not extension); enforce 50MB and 60-minute limits.
- (capability) CAP-2 Transcription with speaker diarization; identical audio (SHA-256) returns cached transcript instantly.
- (capability) CAP-3 Injection detection: 22 regex patterns block adversarial transcripts before any LLM call.
- (capability) CAP-4 PII redaction: SSN, credit card, email, phone stripped before any LLM call (GDPR/CCPA).
- (capability) CAP-5 Structured summary: call purpose, action items, sentiment trajectory, entities; schema-validated (Pydantic).
- (capability) CAP-6 QA scoring on five weighted dimensions; overall recomputed deterministically in Python, LLM overall discarded (guardrail against drift).
- (capability) CAP-7 Report: PDF + JSON per call, SQLite persistence, append-only audit log.
- (capability) CAP-8 Provider switch: OpenAI / Gemini / Groq via one env var, no code edits; graded requirement (20% of grade).
- (capability) CAP-9 Gradio Analyze Call tab: upload audio, view results, get report.
- (capability) CAP-10 Gradio Observability dashboard tab; contents unspecified in source.
- (constraint) QA weights fixed: Professionalism 15%, Empathy 20%, Resolution 30%, Compliance 20%, Clarity 15%.
- (constraint) No LLM receives a transcript before injection screening and PII redaction (stages 3,4 precede 5,6).
- (constraint) Python 3.11 or 3.12 only; not 3.13.
- (constraint) Must run on CPU laptops: whisper size via WHISPER_MODEL_SIZE; tiny for dev (large-v3 >25 min/call on CPU); 1-3GB weights download on first run.
- (constraint) Multi-provider factory mandatory even though demo likely runs OpenAI.
- (constraint) 100+ tests across unit, integration, security suites.
- (constraint) Free tiers bound alt providers: Gemini 1,500 req/day, Groq 30 req/min.
- (constraint) Fixed stack: LangGraph, faster-whisper (CTranslate2, int8), Pydantic v2, SQLite+SQLAlchemy, ReportLab, Gradio 5.x, pytest, ruff, LangSmith (optional). Detail in stack.md.

- (assumption) Single-user local deployment; no auth or multi-tenancy.
- (assumption) 5,000 calls/day is problem backdrop, not a throughput target.
